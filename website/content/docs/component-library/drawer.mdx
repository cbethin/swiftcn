## Use it

Import `SwiftCN` to use `CNDrawer` directly. This complete example also runs in the native component gallery.

```swift title="DrawerExample.swift"
import SwiftUI
import SwiftCN

struct DrawerExample: View {
    @State private var presented = false

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            CNDrawer(isPresented: $presented) {
                CNDialogTitle("Activity")
                Text("On iOS, drag between medium and large detents. macOS uses a native sheet.")
                CNDialogClose()
            } label: { Text("Show activity") }

        }
    }
}
```

## Native behavior

Uses a native sheet. iOS supports medium and large detents and a drag indicator. macOS retains its native sheet presentation.

## Style and compose

Visual recipes use `.tw` classes. Append `classes:` to override a recipe locally, or change the recipe in `TWGlobalRules.named` for your subtree. Native layout and interaction modifiers remain SwiftUI APIs. For control colors, append `cn-tint-[primary]`, another theme token, or an interpolated `Color`.

Motion recipes are editable too: `control-motion` uses a 150 ms smooth response, `disclosure-motion` uses a 250 ms spring, and `feedback-motion` uses a 200 ms smooth response. Set a recipe to `animate-none` in your global rules to turn it off. Presets respect Reduce Motion. Static components stay still; native scrolling, drag tracking, and platform presentation keep their own gestures.

Action groups and card, dialog, and questionnaire footers stack when their content does not fit. The native layout preserves the same child controls during this change.

View builders preserve native child content. Native Button roles, labels, keyboard shortcuts, submit actions, and presentation modifiers still work. A string recipe does not replace a native control API or a typed chart mark.

/// Pointer entry opens after a short delay. Pointer exit allows travel into the popover.
/// Explicit activation keeps the popover open until native outside or keyboard dismissal.
public struct CNHoverCard<Label: View, Content: View>: View {
    @State private var isPresented = false
    @State private var triggerHovered = false
    @State private var contentHovered = false
    @State private var openedByHover = false
    private let classes: TWClasses
    private let label: Label
    private let content: () -> Content
    public init(_ classes: TWClasses = "", @ViewBuilder content: @escaping () -> Content, @ViewBuilder label: () -> Label) {
        self.classes = classes; self.content = content; self.label = label()
    }
    public var body: some View {
        CNButton(variant: .outline, classes: classes, action: { openedByHover = false; isPresented.toggle() }) { label }
            .onHover { triggerHovered = $0 }
            .popover(isPresented: $isPresented) {
                content().tw("hover-card").onHover { contentHovered = $0 }
            }
            .onChange(of: isPresented) { _, presented in if !presented { openedByHover = false; contentHovered = false } }
            .task(id: triggerHovered || contentHovered) {
                let hovering = triggerHovered || contentHovered
                do { try await Task.sleep(for: .milliseconds(200)) } catch { return }
                guard !Task.isCancelled else { return }
                if hovering && !isPresented { openedByHover = true; isPresented = true }
                else if !hovering && openedByHover { isPresented = false }
            }
    }
}
