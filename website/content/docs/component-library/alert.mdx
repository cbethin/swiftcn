## Use it

Import `SwiftCN` to use `CNAlert` directly. This complete example also runs in the native component gallery.

```swift title="AlertExample.swift"
import SwiftUI
import SwiftCN

struct AlertExample: View {

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            CNAlert {
                Label("Changes saved", systemImage: "checkmark.circle").tw("alert-title")
                CNAlertDescription("Your workspace is up to date.")
            }

        }
    }
}
```

## Native behavior

Compose native content in the builder. Pass classes: to replace or extend the default recipe. Bindings and application actions remain caller-owned. Layout, semantics, and system control behavior remain native.

## Style and compose

Visual recipes use `.tw` classes. Append `classes:` to override a recipe locally, or change the recipe in `TWGlobalRules.named` for your subtree. Native layout and interaction modifiers remain SwiftUI APIs. For control colors, append `cn-tint-[primary]`, another theme token, or an interpolated `Color`.

View builders preserve native child content. Native Button roles, labels, keyboard shortcuts, submit actions, and presentation modifiers still work. A string recipe does not replace a native control API or a typed chart mark.
