```swift
Button("Save", action: save)
    .buttonStyle(.tw(.primaryButton))
    .disabled(isSaving)

Button("Delete", role: .destructive, action: delete)
    .buttonStyle(.tw(.destructiveButton))
```

Built-in recipes include `card`, `primaryButton`, `secondaryButton`, `outlineButton`, and `destructiveButton`.
The button adapter uses `ButtonStyle.Configuration.isPressed`.
SwiftUI retains the button's action, semantic role, and activation behavior.
Appearance variants do not set semantic roles.
Button recipes use a minimum height of 44 points on iOS and 32 points on macOS.
Large text can increase that height.

```swift
TWStyle(
    .opacity(1),
    .hover(.bg(.accent)),
    .pressed(.opacity(0.8)),
    .disabled(.opacity(0.45))
)
```

Active patches apply after base utilities.
State precedence is hover, focus, pressed, then disabled.
For equal precedence, more specific nested conditions win before declaration order.
Conditions affect appearance only.
Use native `.disabled(...)` to disable a control.

Hover follows native pointer events.
General view styling does not recognize presses or assign focus.

## Focus

Supply explicit focus state when a control owns it.
This complete view keeps focus and text editing native:

```swift title="FocusExample.swift"
import SwiftUI
import SwiftCN

struct FocusExample: View {
    @State private var email = ""
    @FocusState private var emailFocused: Bool

    var body: some View {
        TextField("Email", text: $email)
            .textFieldStyle(.plain)
            .focused($emailFocused)
            .tw(.p(3), .border(.border), .rounded(.md),
                .focus(.border(.primary, width: 2)),
                state: TWState(isFocused: emailFocused))
    }
}
```

## Other native controls

Use native style adapters when you want shared control defaults:

```swift
TextField("Email", text: $email).textFieldStyle(.tw())
SecureField("Password", text: $password).textFieldStyle(.tw())
Toggle("Notifications", isOn: $notifications).toggleStyle(.tw(base: .switch))
Label("Workspace", systemImage: "folder").labelStyle(.tw())
```

See [composable components](/docs/components) for card parts, field validation, custom control content, and editable rules.
General `.tw` decoration remains available alongside these adapters:

```swift
TextField("Email", text: $email)
    .textFieldStyle(.plain)
    .tw("p-3 rounded-md border bg-surface")

Toggle("Notifications", isOn: $notifications)
    .tw("p-3 rounded-lg bg-surface")

Slider(value: $volume)
    .tw("p-4")
```

Use `.buttonStyle(.tw(...))` for a button's pressed appearance. A general `.tw(...)` surface does not invent press gestures.

Use native gesture modifiers, accessibility labels, bindings, and presentation APIs alongside your styles.
